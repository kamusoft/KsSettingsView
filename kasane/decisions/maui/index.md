# maui ADR 一覧

| ID | タイトル | status | 概要 |
|---:|---|---|---|
| [0001](0001-maui-bridge-dsl-variant-internal-store.md) | MAUI Bridge は内部所有 Store を持つ DSL 方式の類型 | accepted | Bridge は Native 側に内部所有 Store を持ち、公開 API を Store 公開操作へ変換して既存の収束経路に乗せる。 |
| [0002](0002-bridge-api-per-store-operation.md) | Bridge 公開 API は Store 操作と 1:1 / replaceCells を iOS へ対称化 | accepted | union DTO をやめ Store 公開操作 1:1 の12メソッドにする。replaceCells は iOS Store 本体へ追加して Android と対称化。 |
| [0003](0003-single-interaction-delegate.md) | ユーザー操作通知は単一 delegate/listener に集約 | accepted | Native → C# の操作通知を SettingsView あたり1個の delegate に集約し、Cell 種別はメソッド名で識別する。 |
| [0004](0004-maui-idiomatic-types-for-styling.md) | Theme / CellStyle は MAUI 慣例型で公開 | accepted | 公開 API は Microsoft.Maui.Graphics 等の MAUI 型、interop DTO は非公開の輸送表現。固有項目は接頭辞付き nullable。 |
| [0005](0005-bridge-ownership-model.md) | Bridge は Store と Host を所有し独立モジュールで生成・破棄を担う | accepted | Host は Bridge が生成・公開 (同時1個)。破棄は冪等で破棄後は no-op。UI スレッドは呼び出し側契約。 |
| [0006](0006-android-binding-gradlew-exec.md) | Android Binding は AndroidGradleProject ではなく gradlew 直接実行方式を採る | accepted | SDK init script の buildDirectory 束ねで複数モジュール構成が壊れることを実測確認。aar は gradlew Exec で生成し AndroidLibrary で束縛。SDK 対応時に見直す。 |
| [0007](0007-release-host-without-bridge-dispose.md) | Bridge に Host 単独解放 (releaseHost) を追加し Host の寿命を Handler 接続に合わせる | accepted | releaseHost は Host のみ解放し Store 維持。解放後の makeHost* は Store 現在状態から復元した新 handle を返す。ADR-0005 の生成制約を一部置き換え。 |
| [0008](0008-aiforms-compatible-api-surface-policy.md) | MAUI 公開 API は AiForms 互換命名を基本とし、現行コア契約に無い機能は互換提供せず Native から再設計する | accepted | 対応概念ありは AiForms 命名踏襲、font は分割公開+facade 合成、Tapped 非共通化、ItemsSource は MAUI 層で閉じる。 |
| [0009](0009-net10-tfm-and-gateway-seam.md) | MAUI facade は素の net10.0 TFM を持ち Bridge 呼び出しを internal gateway 抽象で隔離する | accepted | 変換経路の純ロジックを platform 非依存に置き、fake gateway を注入した net10.0 ユニットテストで網羅する。後続 Cell フェーズのテスト戦略を規定。 |
| [0010](0010-androidx-conflict-absorbed-in-binding-layer.md) | AndroidX 依存の版競合は Binding 層の明示宣言で吸収し利用者アプリにピンを書かせない | accepted | Binding.Android が LiveData 2.11.0.1 を明示宣言し family 整合を取る。アプリ側ピンは no-op と判明し不採用。ProjectReference 経路は restore + mutation probe で実証済み、NuGet 経路は未検証。 |
| [0011](0011-per-type-cell-dto-transport.md) | Cell の輸送は per-type 展開 (facade 派生・Snapshot・Bridge DTO を種ごとに 1:1) | accepted | 単一 wide DTO + cellType 判別は判別の二重化と ADR-0002 の union 却下経緯との不整合で却下。ToDto() は型スイッチ化。異種混載のため共通基底 DTO `KsBridgeCell` を新設。 |
| [0012](0012-interaction-value-transport-contract.md) | 双方向値の輸送規約 — 壁時計値は ISO-8601 文字列、選択は index、書き戻しは必須コミット | accepted | 通知時点で Store は旧値のため書き戻しは必須コミット。Time/Date は "HH:mm"/"yyyy-MM-dd"、Picker は index 輸送で SelectedItem 解決は facade。エコー抑止は書き戻し入口の同値チェック (CellBase 現値比較)、ShouldPublish() は撤去。書き戻し正規一覧は 10 プロパティ (TwoWay 既定)。 |
| [0013](0013-datepicker-uistyle-unified-enum.md) | DatePicker の uiStyle は MAUI 統一 enum `DatePickerUIStyle { Calendar, Wheels }` で意味マッピング | accepted | Calendar → iOS .calendar / Android Material、Wheels → iOS .wheels / Android Spinner。null = native 既定。AndroidButtonColor は接頭辞付き維持。 |
| [0014](0014-android-host-measure-contract-fill-with-unbounded-fallback.md) | MAUI Android Host の measure 契約 — 大きさが決まる配置は fill 即答、内容サイズを問われる配置のみ platform measure | accepted | SettingsView **自体の置き場所** (親レイアウト) の話で、内側の Cell 種には無関係。Grid `*` 行等の通常配置ではフォーカス喪失経路 (measure 中 layout → EditText ゼロ幅化 → clearFocus) を GetDesiredSize override で遮断。VerticalStackLayout 直下等の内容サイズ配置は従来どおり降ろして iOS と挙動を揃える。 |
| [0015](0015-iconsource-materialized-via-image-source-service.md) | CellBase.IconSource は image source service で非同期実体化し platform 画像を輸送 | accepted | 接頭辞付き platform プロパティ案は MAUI 画像資産が使えず却下。解決は KsSettingsController 所有、単調増加トークンで latest-wins、結果は KsImageLease として破棄管理。native は KsImage の platform case で受け native 変更なし。 |
| [0016](0016-mauiview-materialization-self-measuring-wrapper.md) | MauiView の native 実体化は自己計測 wrapper を産物とする三層構造 | accepted | Handler 注入 seam・controller 所有・gateway 輸送の三層で、seam の産物は MAUI 公式骨格で組んだ自己計測 wrapper platform view。論理所有 (logical tree + BindingContext) は View プロパティ寿命、platform lease は Host 世代で分離。退役は「Store 更新 → native 配信 → 破棄」の順序 + 同一 View 包み直し前の先行破棄 (Handler 1:1)。Header/Footer と CustomCell content の共有部。 |
| [0017](0017-accessory-view-instance-transport.md) | accessory の任意 View は native view インスタンスを直接輸送し Bridge が定数返し closure で包む | accepted | 新 API updateAccessoryView と KsBridgeSection の view フィールドで platform view を素通し輸送。factory 輸送は Handler 1:1 制約で無意味、binding 拡大は @objc 非互換で却下。closure 内で detach してから返す (Android は detach なしで crash を実測)。退役 view の剥がしは ADR-0016 の破棄手順が担う。 |
| [0018](0018-accessory-view-update-semantics.md) | view accessory の更新は明示経路のみを正とし、内容変化は live view + wrapper 中継で追従 | accepted | 差し替えは updateAccessoryView で必ず再発行 (Store に同値スキップ無しを実証)。内容変化は再発行せず live 描画。iOS は対象限定 invalidateLayout が要ることを実測確定し、native 再計算口 invalidateAccessoryMeasurement (Store 一過性通知) を追加。値比較経路を view 変更輸送に使わない。 |
| [0019](0019-customcell-only-no-user-defined-cell-registry.md) | MAUI のカスタムセルは CustomCell (content + builder) までを提供し、利用者定義 Cell (Registry 公開) は提供しない | accepted | カスタムセル3層の①②相当のみ提供。③は per-type 輸送に利用者型が乗らず Swift/Kotlin Renderer を強いるため非提供。後付け追加は可逆。 |
| [0020](0020-customcell-content-live-view-generation-token.md) | MAUI CustomCell の content は live view + 世代トークンで輸送し、埋め込み view の差し替えはトークン変更でのみ起きる | accepted | CustomCell は MauiView を保持し内容は live 更新。保証は埋め込み view インスタンスの安定性 (native 再バインド自体は他の等価性参加者でも発火)。行高さは wrapper 自身の計測無効化で追従 (native 通知不要を probe 実測)。実体化は ADR-0016〜0018 の共有機構を再利用。 |
| [0021](0021-customcell-cellbase-inheritance-silent-noop-surface.md) | MAUI CustomCell の公開面は CellBase 継承 + Content で構成し、継承で来る不適用プロパティは silent no-op で露出のまま維持する | accepted | Content (ContentProperty) + Command/Tapped/ShowArrowIndicator。new 隠蔽は XAML/Binding/基底型アクセスに効かず却下、例外送出は却下 (なお共有 Style は CellBase に適用不能と実装時判明)。IsMeasureOnce 等の AiForms 固有は非提供。 |
| [0022](0022-view-placement-guard-pre-commit-validation.md) | View 配置プロパティの多重配置検査は値確定前 guard で行い、失敗時は旧状態を保全する | accepted | validateValue から controller guard へ尋ね、失敗時は公開値・所有・実体・表示を動かさない (false 返却は ArgumentException 化のため例外送出)。バッチは native 前に全件検査。公開コレクションは非ロールバックで回復は Root 全体再構築。guard は弱参照 (強参照はリーク実測で却下)。 |
| [0023](0023-liststyle-property-independent-of-theme.md) | style は非 nullable の `ListStyle` プロパティとして Theme と独立経路で公開する | accepted | 統一 enum `SettingsViewStyle { Classic, Modern }` を新設し既定 Classic。`Style` は VisualElement.Style と衝突。Theme snapshot に同梱せず独立の SetStyle 経路で Bridge へ伝搬 (Native の Theme/style 分離と対称)。 |
| [0024](0024-sectionmargin-thickness-logical-direction.md) | SectionMargin は Thickness で公開し Left / Right を leading / trailing として解釈する | accepted | Thickness? (null = platform 既定委譲) で公開し論理方向として Native の directional 型へ直接写す。RTL は Native の解決機構に委ね MAUI 層は FlowDirection を監視しない。独自 directional 型・MAUI 側 FlowDirection 変換は却下。 |
| [0025](0025-nuget-three-package-root-namespace.md) | MAUI は facade + binding 2 件の 3 NuGet パッケージで配布し、名前空間は `KsSettingsView`・Package ID は `KsSettingsView.Maui` とする | accepted | pack は SDK 標準経路のみ。名前空間は文脈内で読まれるため `.Maui` を外し、Package ID は文脈なしで読まれるため修飾を残す。メタデータは maui/Directory.Build.props、版は CPM。 |
| [0026](0026-ios-icon-cleanup-via-ownership-classification.md) | iOS の icon 後片付けは解決時の所有権分類で守る (共有 UIImage を破棄しない) | accepted | キャッシュ所有画像には後片付け口を付けない。判定はキャッシュ引き直し + ReferenceEquals の実体同一性のみ (分岐ミラー禁止)、失敗は破棄しない側へ倒す。Android の破棄は現行維持 (Glide refcount で必須)。 |
