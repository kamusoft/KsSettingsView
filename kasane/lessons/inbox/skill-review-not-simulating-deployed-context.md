## ルール文 (候補)

配布されて単体で使われる成果物 (Agent Skill・テンプレート・コピーして使うドキュメント) のレビュー・初見レビューは、リポジトリ内で読むのではなく**配布後の文脈を模擬して行う**: 対象 1 ディレクトリだけをコピーした状態を作り、(a) 成果物外のファイル・URL への参照が残っていないか (参照は名前のみの言及に落ちているか)、(b) 冒頭でそれ自体が何であるかを自己紹介しているか、(c) 見出し・用語が文書単体の文脈で成立するか (内部用語・アーキテクチャ用語の漏出がないか) を検収基準に含める。事後判定: レビュー証跡に「単体コピー状態での検査」の記録がある。

## 経緯

- 2026-08-26 rollout-user-skills: コピー後のリンク切れ問題はレビューで検出されたが、修正が「相対リンク → GitHub URL 化」に倒れ、全レビュアーがそれを許容した。オーナーの基準は「URL 化」ではなく「SKILL 外参照ゼロ (スキル名のみ言及)」であり、単体利用の閉世界性という観点自体がレビュー基準に無かったのが根因。
