## ルール文 (候補)

「〜は存在しない」を報告・記録に書くときは、マッチ 0 件でも正常終了する手段で確かめ、使ったコマンドかその空の出力を同じ報告・記録に併記する。`find <root> -name '<pattern>'` と `git ls-files '<pattern>'` は 0 件でも exit 0 で終わり、0 件であることが出力の空で分かる。`grep -rl` は 0 件で exit 1 を返すので、`|| true` で握らず exit status そのものを結果として読む。

「見つからなければフォールバックで『なし』と出す」形 (`ls A* B* 2>/dev/null || echo "なし"` など) は使わない。フォールバックは対象が無いときと検索自体が失敗したときの両方で発火し、成果物に残るのは同じ「なし」だけなので、後から区別できない。検索対象の指定 (glob) をシェルに解釈させる形も避ける — 不一致 glob の扱いはシェルによって違い (コマンドごと中断する / リテラルのまま渡す)、同じコマンドが環境をまたいで同じに働かない。複数のパターンを確かめるときは 1 コマンドに並べず、パターンごとに実行する。

事後判定: 不在を断定した報告・記録に、使った検索手段のコマンドか、その 0 件出力が併記されている。
