# Deviation: add-android-maven-distribution

- Requirement「Maven 発行物の座標と内容」/ Scenario「発行メタデータの依存スコープ」: spec は `api` 対象を compose runtime / compose-ui / kotlinx-coroutines-core / androidx.annotation の 4 件と列挙 → オーナー指示により `androidx.recyclerview:recyclerview` を追加で `api` に含める。理由: 公開クラス `CellViewHolder` が `RecyclerView.ViewHolder` を継承しており、design Decision 6 の原理 (公開 ABI に露出する外部型は利用者の compile classpath に届ける) を適用すると該当する列挙漏れ。独自 Cell 経路でも「依存 1 行で完結」(android/ADR-0016) を成立させる。適用に伴い、samples/android が保険として明示宣言していた recyclerview 依存 1 行を削除 (本体の `api` から推移するため冗長化。Sample ビルドで推移の実効を確認済み) (2026-09-01)
- 同 Requirement / Scenario: spec の `api` 列挙 4 件 → レビュー (review-001 / second-opinion-code-001 双方一致の Major) により `androidx.compose.foundation:foundation-layout` も `api` に追加。理由: 公開 data class `Theme` の `sectionMargin: PaddingValues?` が同 artifact の型を公開 ABI に露出しており、上記 recyclerview でオーナーが承認した原理 (design Decision 6 — 公開 ABI に露出する外部型は `api`) の同一適用。宣言元 artifact を直接 `api` に置く (`foundation` の格上げは api 連鎖が間接的なため不採用) (2026-09-01)
