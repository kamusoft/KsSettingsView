公開 API に型が現れる依存がすべて compile スコープに載っている。内訳と根拠:

  compose runtime          KsAnyView.Compose の @Composable () -> Unit
  compose ui               Theme の Color / TextStyle / Dp
  compose foundation-layout  Theme.sectionMargin の PaddingValues
  kotlinx-coroutines-core  SettingsRootStore.state / .theme の StateFlow
  androidx.annotation      KsImage.Resource の @DrawableRes
  recyclerview             CellViewHolder が継承する RecyclerView.ViewHolder

foundation-layout は宣言元 artifact を直接 api に置いている。foundation の
androidApiElements には foundation-layout が含まれず、foundation を api へ格上げしても
成立は間接的になるため。foundation 自身は内部利用のみで runtime スコープに残る。
