端末での確かめ: 進んで戻った後のスクロール位置 (修正前後の A/B)

環境: Android Emulator (API 36、1080x2400)、samples/android の debug ビルド
ビルド: before = 既定 id の View Host を window の階層全体 (rootView) で数える判定に戻したライブラリ / after = 保存の入れ物の範囲で数える判定のライブラリ。サンプル側のコードは両方とも同じ
手順 (各ビルドで同じ。場面 1 と場面 2 の前にアプリのデータを消して起動し直す):
  場面 1: ルートメニュー → スクロール制御デモ →「Section へ」→ TopAppBar の「メニューを開く」(KsSettingsView を使わない画面) → 戻る
  場面 2: ルートメニュー → スクロール制御デモ →「Section へ」→ TopAppBar の「次のデモへ進む」(Store 方式デモ = KsSettingsView の画面) → 戻る
  場面 4: 場面 2 の続きで (位置が先頭へ戻っていたら「Section へ」をもう一度押してから)「メニューを開く」→ 戻る
観測: 画面の要素一覧から、タイトルと、上から 4 つの文字の要素と上端の座標 (px) を読んだもの。「Section 4@300」が上端にあれば位置が保たれている。「操作@358」が上端にあれば内容の先頭へ戻っている
静止画: 各場面の「戻った後」を scroll-control-scene<場面>-return-<before|after>.png に置いた
