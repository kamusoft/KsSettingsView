view accessory × headerHeight — 3状態の規範図解

本 mock は挙動契約の図解であり、配色・寸法・フォントは非規範 (Sample テーマの近似)。規範は各状態の高さの決まり方と clip の有無のみ。 Header 領域 (薄青) が view accessory、その下が通常の Cell 行。

A. 自動高さ (headerHeight = -1)

Header 領域は view の内容なりの高さになる。既定の体験。
