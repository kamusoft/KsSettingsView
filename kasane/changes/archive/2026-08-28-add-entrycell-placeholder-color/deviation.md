# Deviation: add-entrycell-placeholder-color

- [付随修正] `ios/Sources/KsSettingsViewUI/Theme.swift` の doc comment 3 箇所 (`backgroundColor` / `cellTitleColor` / `cellTitleFont`) にあった履歴記述 (旧名からのリネーム経緯・change 識別子の裸参照) を削除。comment-policy の禁止類型に該当し、本務で触れたファイル内・コメントのみの局所修正のため同梱 (2026-08-27)
- [付随修正] `samples/maui/KsSettingsView.Sample.Maui/SampleTheme.cs` の doc コメント `<see cref="EntryCell.PlaceholderColor"/>` が `Microsoft.Maui.Controls.EntryCell` と衝突して CS1574 警告となったため `KsSettingsView.Maui.EntryCell.PlaceholderColor` へ完全修飾。本 change の追加コードが直接原因の 1 行修正のため同梱 (2026-08-27)
- [波及] Android の valueText 色の最終段を固定黒 (`Theme.DEFAULT_CELL_TITLE_COLOR`) からホストテーマの既定文字色 (`android.R.attr.textColorPrimary`) へ是正した (`EffectiveStyle.from`)。`EffectiveStyle.valueTextColor` は全 Cell 共通のため、`EntryCell` だけでなく valueText を描画する全 Cell 型 (`applyCellBaseLayout` 経由の 11 種: Label / Command / Button / Switch / Checkbox / Radio / SimpleCheck / Picker / NumberPicker / DatePicker / TimePicker。根拠 `android/ks-settingsview-ui/src/main/kotlin/jp/kamusoft/kssettingsview/ui/CellBaseLayout.kt:547`) の valueText も「`CellStyle.valueTextColor` / `Theme.cellValueTextColor` / `Theme.cellTitleColor` がすべて未指定」の構成でのみ色が変わる (ダークテーマで黒 → 明色)。iOS の同段 (`UIColor.label` 相当) との一致であり、spec が要求する「platform default」への是正だが、`EntryCell` 以外にも及ぶ利用者可視の変化のため記録する (2026-08-27)。オーナー承認済み — 「このまま受け入れる」を選択 (2026-08-27)
