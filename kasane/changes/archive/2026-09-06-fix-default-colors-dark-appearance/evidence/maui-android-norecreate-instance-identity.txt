MAUI Android — 夜間モード切替の前後で Activity / KsSettingsView のインスタンスが同一であることの記録

採取: 2026-09-05、Android Emulator `ksn_custcell_api35` (Android 15)。Sample の外観は「システム」。
`samples/maui/.../Platforms/Android/MainActivity.cs` の `Recreate()` を一時的にコメントアウトした
ビルドで、`adb shell cmd uimode night no|yes` により端末の夜間モードを切り替えた。
インスタンス識別は `adb shell dumpsys activity top` の出力から、対象アプリの
`ACTIVITY` 行 / `Local Activity <identityHashCode>` 行 / View 階層の該当 2 行だけを抜粋した
(全文はスクラッチに保管。他アプリ・ランチャの行は採らない)。

(再生成されている)、識別子が切替で変わり得ること自体は確認できている。

(c) isVisible デモ (明示色) — Cell 背景 #FFD9E6 → #102A54、Section Header 文字 #C2185B → #7FD4FF。
    同画面の未指定色も list 下地 #FFFFFF → #000000 へ追随した。
