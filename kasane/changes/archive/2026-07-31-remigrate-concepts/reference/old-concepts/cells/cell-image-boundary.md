## 所有境界

Cell の icon は Core の構造モデルではなく UI 層が所有する。各プラットフォームで自然な画像入力を受け取れる一方、Cell の内容比較と宣言 DSL の再評価に参加できる判別可能な値として扱う。

この境界は、画像と Native スタイル値を UI 層に隔離する [ADR-0009](../../decisions/0009-ui-layer-native-styling.md) の具体化である。

## 値同一性

名前やリソース識別子のような記述的入力は、その記述値で等価性を判定する。

Native 画像オブジェクトには一般的な内容等価を仮定しない。同じインスタンスを保持する場合だけ等価とし、画像データの走査や暗黙の正規化を値比較へ持ち込まない。

## 解決とフォールバック

プラットフォーム間の API 対称性のために受理した表現を現在のプラットフォームで解決できない場合は、例外や描画失敗ではなく「icon なし」へ安全にフォールバックする。

icon がない場合と解決できない場合は、どちらも空の画像領域を残さず、主要内容を自然な先頭位置へ詰める。この配置は [Cell 共通行](styling/cell-row-layout.md)の任意要素の規則に従う。

URL は現在の画像値契約に含めない。将来必要になった場合は、取得、キャッシュ、失敗時表示、ライフサイクルを含む独立した能力として設計する。
