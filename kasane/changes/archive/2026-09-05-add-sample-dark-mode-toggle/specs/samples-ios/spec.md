# Delta: samples-ios (add-sample-dark-mode-toggle)

## ADDED Requirements

### Requirement: 外観の切り替え

iOS サンプルのルートメニューに、外観を「システム / ライト / ダーク」から選ぶ項目群を常設する (SHALL — 見出し「外観」、項目文言は 3 platform で一致させる)。選択はアプリ全体の外観に即時反映され、選択中の項目が識別できる (SHALL)。初回起動時の選択は「システム」で、選択はアプリを再起動しても維持される (SHALL)。

#### Scenario: ダークを選ぶとライブラリ既定色の画面が暗く描画される
- **GIVEN** 端末の外観がライトで、外観の選択が「システム」
- **WHEN** 「ダーク」を選び、Theme を渡していないデモ画面 (例: isVisible デモ) を開く
- **THEN** 画面はライブラリ既定色のダーク描画になり、ルートメニューでは「ダーク」が選択中として識別できる

#### Scenario: システムに戻すと端末の外観に従う
- **GIVEN** 外観の選択が「ダーク」で、端末の外観がライト
- **WHEN** 「システム」を選ぶ
- **THEN** アプリの外観は端末に従いライトに戻る

#### Scenario: 選択が再起動後も維持される
- **GIVEN** 「ダーク」を選んだ状態でアプリを終了する
- **WHEN** アプリを再起動しルートメニューを表示する
- **THEN** 「ダーク」が選択中として識別でき、アプリの外観はダークである

#### Scenario: システム選択中に端末の外観が変わると追随する
- **GIVEN** 外観の選択が「システム」で、アプリを表示中
- **WHEN** 端末の外観をライトからダークへ切り替えてアプリへ戻る
- **THEN** アプリの外観は変更後の端末外観に従う (再開時を含む)

### Requirement: 外観に応じた Sample Theme の差し替え

`SampleTheme` が提供する Theme (AiForms 互換 Theme と Section 装飾デモの下地 Theme) は light / dark の対を持ち、Theme を渡すデモ画面は実効外観がダークのとき dark 側を渡す (SHALL)。実効外観は、外観の選択が「システム」なら端末の外観、それ以外なら選択値で決まる (SHALL)。dark 側は light 側の色ロールに加えて description と valueText の色も明示する (SHALL — 未指定時の既定色が暗い下地に追随しないため)。それ以外の色ロール構成は light 側と同じにする (SHALL — 具体の色値は ui/ のモックが正)。

#### Scenario: ダーク時に Theme 明示の画面が dark プリセットで描画される
- **GIVEN** 実効外観がダーク
- **WHEN** 基本 Cell 7 種デモを開く
- **THEN** 画面は dark 側の Theme で描画され、light 側の配色は現れない

#### Scenario: ライト時は従来どおり light プリセットで描画される
- **GIVEN** 実効外観がライト
- **WHEN** 基本 Cell 7 種デモを開く
- **THEN** 画面は従来の AiForms 互換 (light) Theme で描画される

### Requirement: カレンダー型 DatePickerCell の範囲デモ

入力 Cell 5 種デモの「予約日」(カレンダー型) に、初期値を含む固定の `minDate` / `maxDate` (2026/06/01 から 2026/06/20 まで。初期値 2026/06/01 は変えない) を指定する (SHALL — 3 platform で同じ範囲・同じ初期値)。

#### Scenario: 範囲外の日付は選択できない
- **GIVEN** 「予約日」の選択面を開いた状態
- **WHEN** 範囲外の日付 (同じ月の 21 日以降) を選ぼうとする
- **THEN** その日付は選択不可として提示され、確定しても `date` は範囲内の値のまま変わらない

#### Scenario: 今日が範囲外なら今日ジャンプは選択状態を変えない
- **GIVEN** 「予約日」の選択面を開いた状態で、端末の今日が範囲外
- **WHEN** 「今日」の操作を実行する
- **THEN** 選択状態は変わらず、行の値も変わらない
