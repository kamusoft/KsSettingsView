# KsSettingsView — Swift Package Manager distribution

This repository is a **distribution mirror**. It contains a snapshot of the iOS Swift package
so that Swift Package Manager can resolve it from a repository root, and nothing else.

Source code, documentation, issues, and pull requests all live in the main repository:

**https://github.com/kamusoft/KsSettingsView**

## Installation and usage

Installation instructions, supported versions, and usage guidance are published in the main
repository — see its [README](https://github.com/kamusoft/KsSettingsView#readme) and the
platform Agent Skills it links to.

## Issues and contributions

Do not open issues or pull requests here. This repository is generated from the main
repository and any change made directly to it is overwritten by the next release.

Report problems and propose changes at
**https://github.com/kamusoft/KsSettingsView/issues**.
